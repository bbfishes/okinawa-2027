# Okinawa 2027 沖繩七天六夜自駕之旅

這是一個用於規劃 2027/1/13 - 2027/1/19 沖繩旅遊行程的開源專案，採用響應式 HTML/Tailwind CSS 撰寫，方便直接透過 GitHub Pages 預覽與分享行程。

## ✈️ 航班資訊
* **航空公司：** 中華航空 (China Airlines)
* **日期：** 2027/1/13 - 1/19
* **旅遊形式：** 雙人自駕旅遊

## 🏨 住宿安排
* **Day 1 - Day 3:** KARIYUSHI LCH. RESORT on The Beach (中北部 / 高CP值海濱)
* **Day 4 - Day 6:** 沖繩那霸旭橋托里菲托酒店 (那霸市區 / 便利質感)

## 🗂 檔案結構
- `index.html`: 行程總覽網頁，使用 Tailwind CSS 與 FontAwesome 進行視覺設計。
- `README.md`: 專案說明文件。

## 🚀 部署方式 (GitHub Pages)
1. 將此專案推上您的 GitHub Repository (例如 `okinawa-2027`)。
2. 至 Repository 的 **Settings** > **Pages**。
3. Source 選擇 `Deploy from a branch`，Branch 選擇 `main`，點擊 Save。
4. 稍等片刻，即可透過 `https://<您的帳號>.github.io/okinawa-2027/` 在手機與電腦上隨時檢視精美行程。
